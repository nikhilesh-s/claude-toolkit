# Brag Plan: claude-toolkit

## What is this app?
A dotfiles repo tracking one dev's Claude Code setup: 175 skills, 72 plugins, symlinked from one git repo into `~/.claude/`.

## The angle
Deadpan startup-metrics energy applied to a personal dotfiles repo. Treat "175 skills, 72 plugins" like a funding-round stat slide. The joke: total seriousness about a README file.

## Hook (first 2-3 seconds)
Terminal cursor blinks. Line types: `$ ls ~/claude-toolkit/skills | wc -l`. Answer slams in: `175`.

## Key moments (the middle)
- Stat cards count up one by one: `175 skills` / `72 plugins` / `1 README`.
- A code diff flashes: `-376,132 / +126` — the gstack vendoring mistake fixed in one commit, framed as a flex ("caught our own bloat").
- `git push` line types out, then `main → main` confirms.

## Outro / punchline
Cursor blinks once more. Final line types: `my Claude Code setup got a little out of hand.` Logo/title card: `claude-toolkit`.

## User flow worth showing
none — landing-page only equivalent: this is a terminal + README repo, no app UI. Rely on Key moments instead.

## Tone
- Preset: yc-parody
- Creative direction: fake startup metrics slide, delivered completely straight, about a personal dotfiles repo
- Interpretation: structured pacing, hard cuts, big confident type. The joke is the seriousness, not the jokes.

## Format: landscape — 1920x1080
## Duration: 20 seconds

## Visual identity (from the project)
- Background: near-black terminal, `#0d1117` (GitHub dark)
- Accent: terminal green, `#39d353`
- Text: off-white, `#e6edf3`
- Display font: monospace (SF Mono / JetBrains Mono feel)
- Body font: same monospace, smaller weight
- Strongest visual element: the terminal itself — typed commands, blinking cursor, README markdown table

## Share copy (draft)
175 skills. 72 plugins. One README. My Claude Code setup got a little out of hand.

## Audio direction
- Role: sparse professional accents, motion-matched
- Music: upbeat minimal synth bed, restrained
- Music treatment: starts under the hook at low volume, one swell under the stat count-up, fades under the outro line
- Music cue guidance: to be detected at composition time (no bundled preset chosen yet); target one strong cue at the `175` slam and one at the stat-card sequence start
- Audio-reactive treatment: none
- SFX posture: sparse — key ticks on typed lines, one soft UI-pop per stat card, one confirm chime on `main → main`
- Audio-coupled moments: hook line types with key ticks; each stat card arrives with its own pop; git push confirms with a chime
- Restraint rule: no laugh-track energy, no cartoon SFX — every sound stays inside "real terminal" register

## Storyboard

### Scene 1 — Hook — 3s
Black terminal. Cursor blinks. `$ ls ~/claude-toolkit/skills | wc -l` types out character by character. Answer `175` slams in large, bottom-right.
Sequential/interaction: yes — command types out char by char, then answer slams in after
Audio intent: quiet anticipation building to a punch
Audio-coupled idea: key-tick sounds during typing, single hit on the `175` slam
Music: thin synth bed starts low
Transition mood: hard cut → Scene 2

### Scene 2 — Stat reveal — 5s
Three stat cards arrive one by one, each a full-width terminal-style row: `175 skills`, `72 plugins`, `1 README`.
Sequential/interaction: yes — 3 cards arrive one by one, ~0.8s hold each
Audio intent: confident, building
Audio-coupled idea: soft pop per card arrival
Music: bed continues, slight build
Transition mood: hard cut → Scene 3

### Scene 3 — The fix — 5s
A diff view flashes: `-376,132 insertions` in red strikes through, `+126` in green lands under it. Caption below: `caught our own bloat`.
Sequential/interaction: yes — red line appears first, green line lands after with weight
Audio intent: a small, satisfying "gotcha" beat
Audio-coupled idea: one sharp accent when the green line lands
Music: brief swell
Transition mood: hard cut → Scene 4

### Scene 4 — Ship it — 4s
`$ git push` types out. `main → main` confirms below it in green.
Sequential/interaction: yes — command types, confirmation lands after a beat
Audio intent: resolution, quiet confidence
Audio-coupled idea: key ticks on typing, one confirm chime on the push line
Music: bed settles
Transition mood: clean → Scene 5

### Scene 5 — Outro — 3s
Cursor blinks alone on black. Line types: `my Claude Code setup got a little out of hand.` Title card fades in below: `claude-toolkit`.
Sequential/interaction: yes — line types out, then title card fades in after
Audio intent: dry, deadpan close
Audio-coupled idea: key ticks on the line, no sound on the title card
Music: fades out under this scene
Transition mood: fade to black

**Music mood for this video:** deadpan / yc-parody — restrained minimal synth, not corporate-upbeat
